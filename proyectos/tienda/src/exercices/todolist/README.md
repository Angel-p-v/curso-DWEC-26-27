# TodoList en TypeScript 

## Especificaciones 

Se desea crear un TodoList para gestionar las tareas en TypeScript 
Se debe tener en cuenta lo siguiente 

- Prohibido usar push,slice,splic,sort.
- Las tareas tienen las prioridades que son low,medium,high
- De una tarea necesitamos el id,title,priority, un check para saber si esta completada o no: done

### Métodos a ejemplificar 

- createTask
- toggleDone
- rename
- removeDone
- editTask
- pendingByPriority

Crear por tanto un main.ts en la carpeta todoList que permita ejemplificar una app de tareas.
